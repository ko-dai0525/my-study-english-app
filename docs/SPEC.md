# 英語学習アプリ 仕様書

PLAN.md のアイデアを拡充した仕様書。実装と差異が出た場合は本書を更新すること。

## 1. 概要

単語・熟語を自分で登録し、「カードめくり」と「クイズ」の2つのモードで反復学習できる、スマホ向けの英語学習アプリ。

## 2. 実現方式

**PWA（Progressive Web App）を採用する。**

| 要件（PLAN.md） | PWA での実現 |
| --- | --- |
| スマホ内で使用する | ブラウザで開き「ホーム画面に追加」するとネイティブアプリ風に全画面起動 |
| お金は最小限 | App Store / Play Store の登録費用が不要。静的ホスティング（GitHub Pages 等）は無料 |
| オフラインで勉強したい | Service Worker がアプリ本体をキャッシュ。初回アクセス以降は圏外でも起動・学習可能 |
| ローカルアプリが理想 | 学習データは端末内（localStorage）にのみ保存。サーバー送信なし |

補足:
- 発音は Web Speech API（`speechSynthesis`）を使用。スマホ OS 内蔵の音声エンジンで読み上げるため、基本的にオフラインでも動作する。
- データは端末内保存のため、機種変更や誤削除に備えて JSON エクスポート／インポート機能を持つ。

| 項目 | 採用技術 |
| --- | --- |

## 4. 機能仕様

### 4.1 単語・熟語の登録・管理（一覧タブ）

- 登録項目: 英語（単語・熟語）/ 意味（日本語）/ 例文（任意）
- 一覧表示（新しい順）。各行に発音ボタン🔊・編集・アーカイブ（戻す）・削除
- 「学習中（n） / アーカイブ済み（n）」のセグメント切替で表示対象を切替（見出しの件数は総数）
  - アーカイブした単語はカード・クイズの出題対象から外れる（「↩️ 戻す」で復帰）
- 一覧は 10 件ずつのページング（「← 前へ | n / m ページ | 次へ →」。1ページに収まる場合は非表示）
- キーワード検索（英語・意味の部分一致。表示中のセグメント内を検索）
- 削除は確認ダイアログを挟む
- 各行には、クイズ成績（累計）と直近5回の自己判定を `履歴: ⭕❌⭕⭕❌`（古い→新しい順）で表示
- 単語を削除するとその単語の判定履歴も一緒に削除される（アーカイブでは履歴を残す）
- 画面下部にデータ管理: JSON エクスポート（ダウンロード）/ インポート（ファイル選択、既存データとマージ。同一 id は上書き）
  - エクスポート形式は `{ version: 2, exportedAt, words, history }`。インポートは旧形式（`WordEntry[]` の配列）も読み込める

### 4.2 カード学習モード（カードタブ）

- 学習中（アーカイブ済みを除く）の単語をシャッフルした順で 1 枚ずつ表示
- カードは表裏構造。タップで反転（3D フリップアニメーション）
  - 出題方向トグルで「英語 → 意味」「意味 → 英語」を切替可能
- 英語面には発音ボタン🔊を表示（タップで読み上げ。カード反転はしない）
- 操作: 前へ / 次へ / 再シャッフル
- 進捗表示（例: 3 / 20）
- 出題方向・並び順・現在位置は localStorage に保存され、タブを移動してもアプリを再起動しても続きから再開できる

### 4.3 クイズモード（クイズタブ）

- 出題方向を選択: 「英語 → 意味」または「意味 → 英語」
- 学習中（アーカイブ済みを除く）の単語からランダム出題（一巡するまで重複しない）
- 回答は自由記述（テキスト入力）
- 回答送信後、**期待していた答えと自分の回答を並べて表示**（自動採点はしない）
  - 補助として、空白・大文字小文字・記号を無視した正規化比較で完全一致した場合は「一致！」バッジを表示
- ユーザー自身が「⭕ 正解」「❌ 不正解」を選んで自己判定 → 単語ごとの成績（出題数・正解数）に記録
- セッション中の成績（正解数 / 出題数）を表示
- 各単語の正答率と直近の判定履歴は一覧タブでも確認できる
- 出題方向・出題順・現在位置・セッション成績は localStorage に保存され、タブを移動してもアプリを再起動しても続きから再開できる（一巡の進捗が失われないため、同じ問題を解き直さずに済む）
- 出題対象の単語が増減した場合（登録・削除・アーカイブ）は、消えた単語を出題順から外し、増えた単語を現在の周回の末尾に追加する

### 4.4 学習記録

- 単語ごとに `quizCount`（出題数）と `correctCount`（自己判定の正解数）を累計で保持
- 加えて、自己判定 1 回ごとに `QuizResult`（単語 / 出題方向 / 正誤 / 日時）を履歴として保存
  - 保存上限は 1000 件。超えた分は古いものから破棄する
  - 一覧タブでは単語ごとに直近5件を `⭕❌` のマークで表示（マークにカーソルを合わせると日時・出題方向・正誤が出る）
- いずれもクイズの自己判定時に更新し、localStorage に永続化

## 5. データモデル

```ts
interface WordEntry {
  id: string;           // crypto.randomUUID()（非セキュアコンテキストでは時刻+乱数のフォールバック）
  term: string;         // 英語（単語・熟語）
  meaning: string;      // 意味（日本語）
  example?: string;     // 例文（任意）
  createdAt: number;    // 登録日時（epoch ms）
  quizCount: number;    // クイズ出題数
  correctCount: number; // 自己判定での正解数
  archived?: boolean;   // アーカイブ済みなら true（カード・クイズの出題対象外）
}

interface QuizResult {
  id: string;           // makeId()
  wordId: string;       // WordEntry.id
  direction: Direction; // 'enToJa' | 'jaToEn'
  correct: boolean;     // 自己判定の結果
  answeredAt: number;   // 判定日時（epoch ms）
}

// 学習セッション（クイズ・カードの進行状況）
interface SessionState {
  quiz: { direction: Direction; queueIds: string[]; index: number; asked: number; correct: number };
  card: { direction: Direction; deckIds: string[]; index: number };
}
```

`queueIds` / `deckIds` には `WordEntry` そのものではなく id を保存する。こうすることで単語を編集した内容が次に開いたときに反映される。

localStorage のキーは以下の3つ。

| キー | 内容 |
| --- | --- |
| `my-study-english-app/words/v1` | `WordEntry[]` |
| `my-study-english-app/results/v1` | `QuizResult[]`（古い順、最大1000件） |
| `my-study-english-app/session/v1` | `SessionState` |

読み込み時はいずれもランタイム型ガードで検証し、不正なデータは黙って除外する（セッションは壊れていれば初期状態に戻す）。`archived` はオプショナルのため単語のキーは v1 のままで、フィールドを持たない既存データ・旧エクスポート JSON もそのまま読み込める（未設定は「学習中」扱い）。履歴とセッションは存在しなければ空として扱うため、既存ユーザーのデータはそのまま使える。

## 6. 画面構成

下部タブナビゲーション 3 タブ構成（スマホ片手操作を想定）。

1. **一覧** — 登録フォーム + 単語一覧（学習中/アーカイブ済み切替・10件ずつページング・成績と判定履歴） + 検索 + データ管理
2. **カード** — カードめくり学習（進行状況を保存し続きから再開）
3. **クイズ** — 自由記述クイズ（進行状況・セッション成績を保存し続きから再開）

## 7. 制約・注意事項

- 学習データは端末（ブラウザ）ごとに保存される。ブラウザのデータ消去で失われるため、定期的な JSON エクスポートを推奨。
- iOS Safari の `speechSynthesis` はユーザー操作起点でのみ再生可能（発音ボタンのタップで対応済み）。
- 音声の品質・利用可否は端末 OS にインストールされている音声エンジンに依存する。
